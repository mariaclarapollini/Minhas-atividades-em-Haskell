Este repositório contém resoulções das listas de Haskell disponibilizadas na disciplina de Programação III ministrada pelo
professor Emanoel Barreiros no curso de Bacharelado em Engenharia de Software na UPE.

Ao longo das listas apliquei os conceitos e princípios fundamentais da linguagem Haskell e seu paradigma funcional.
O conceitos variam entre tipos de dados, compreensão de listas e funções recursivas.
